# Погода и интересные места по названию локации

Консольное приложение на Kotlin. Пользователь вводит название места, выбирает один из найденных вариантов и получает сводку: текущую погоду и список интересных мест рядом с кратким описанием каждого.

Все HTTP-вызовы асинхронные (`HttpClient.sendAsync` + `CompletableFuture`), независимые запросы идут параллельно, зависимые собраны в цепочку без блокировок.

## Используемые API

Ключи не нужны. Адреса всех API вынесены в `Config.kt`.

| Назначение | API | Константа в `Config` |
|---|---|---|
| Поиск локаций по названию | [Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api) | `GEOCODING_URL` |
| Погода по координатам | [MET Norway Locationforecast 2.0](https://api.met.no/weatherapi/locationforecast/2.0/documentation) | `WEATHER_URL` |
| Интересные места вокруг точки | [Wikidata Query Service](https://www.mediawiki.org/wiki/Wikidata_Query_Service/User_Manual) (SPARQL, `wikibase:around`) | `PLACES_URL` |
| Описание места по Q-id | [Wikidata `wbgetentities`](https://www.wikidata.org/w/api.php?action=help&modules=wbgetentities) | `DESCRIPTION_URL` |

## Требования

- JDK 17+
- Gradle (или запуск из IntelliJ IDEA)
- Доступ в интернет

## Настройка
Параметры:

| Константа | Назначение | По умолчанию |
|---|---|---|
| `SEARCH_RADIUS_M` | радиус поиска мест, м | 1500 |
| `MAX_PLACES` | максимум мест в отчёте | 10 |
| `GEOCODING_URL`, `WEATHER_URL`, `PLACES_URL`, `DESCRIPTION_URL` | базовые адреса API | см. файл |

Параметры запросов (название, координаты, SPARQL-запрос) формируются в классах пакета `api`.

## Запуск

Из IntelliJ IDEA: нажмите зелёную стрелку рядом с `fun main()` в `Main.kt`. Ввод с клавиатуры работает в окне Run.

Из терминала:

```
gradle run
```

## Использование

1. Введите название места, например `Москва`, и нажмите Enter.
2. Из списка найденных вариантов введите номер нужного.
3. Дождитесь сообщения «Загружаю данные...». Отчёт выводится один раз, когда готовы все данные.

Пример сессии (сокращённо):

```

2. Москва, Айдахо, США  [46.7324, -117.0002]
...
Выберите номер: 1
Загружаю данные...

=== Москва, Россия  [55.7520, 37.6178] ===

Погода (MET Norway):
```

## Что делает система

1. **Поиск локаций** (`LocationService`). Запрос к Open-Meteo Geocoding возвращает до 8 вариантов с названием, регионом, страной и координатами.
2. **Отчёт** (`ReportService`). После выбора локации сразу параллельно стартуют две ветки:
    - **Погода.** Запрос к MET Norway по координатам. Берутся температура, ветер, влажность и состояние неба на ближайший час.
    - **Места.**
        1. SPARQL-запрос к Wikidata (`wikibase:around`) возвращает объекты с координатами в радиусе `SEARCH_RADIUS_M`: достопримечательности, музеи, памятники, замки, храмы и парки (с подклассами), отсортированные по расстоянию. Объекты без названия отбрасываются.
        2. Для каждого найденного места параллельно запрашивается описание из Wikidata по его Q-id (сначала на русском, при отсутствии на английском).
3. **Сборка и вывод.** Результаты обеих веток объединяются в один объект `Report`, и только после этого `ConsoleApp` печатает его. Поэтапного вывода нет.

Если одна ветка упала (например, Wikidata вернул ошибку), в отчёте для неё будет сообщение об ошибке, а остальные данные всё равно покажутся. Если не удалось получить описание одного места, оно выводится как «описание отсутствует».

## Возможные проблемы

| Симптом | Причина |
|---|---|
| Программа сразу завершается после запуска через `gradle run` | Не подключён ввод, добавьте `standardInput` в `build.gradle.kts` или запускайте из IDEA |
| `HTTP 403` от `api.met.no` или `query.wikidata.org` | Не заменён `USER_AGENT` или он слишком общий |
| `HTTP 429` от `query.wikidata.org` | Слишком частые запросы, подождите минуту |
| `HTTP 500` или `request timed out` от `query.wikidata.org` | Слишком тяжёлый запрос, уменьшите `SEARCH_RADIUS_M` |
| «ничего не найдено в радиусе…» | В Wikidata рядом нет подходящих объектов (бывает в малых населённых пунктах), увеличьте `SEARCH_RADIUS_M` или выберите другое место |
| Ошибки компиляции про `geobrief.*` | После переименования пакета не обновились `package` и импорты |
